# ⚔️ Gulce_AdminPower
Minecraft Java Edition için admin yönetim datapack'i.

## ✨ Özellikler
- 👑 Owner, Admin, Mod, VIP izin sistemi
- ⚡ Toplu işlemler (TP, hız, körlük, yıldırım...)
- ⏱️ Cooldown sistemi
- 🎯 Trigger tabanlı menü arayüzü
- 📜 Token sistemi

## 📦 Bağımlılıklar
Bu datapack çalışmak için **macroEngine-dp**'ye ihtiyaç duyar.
- 🔗 [macroEngine](https://github.com/tickwarden/macroEngine-datapack)

> ⚠️ macroEngine-dp kurulu olmadan AdminPower düzgün çalışmaz!

## 🚀 Kurulum
1. Önce [macroEngine](https://github.com/tickwarden/macroEngine-datapack)'yi indir ve kur
2. `Gulce_AdminPower_v*.zip` dosyasını çıkartmadan `dünya/datapacks/` klasörüne koy
3. Oyunda `/reload` çalıştır
4. `/function custom:perm/set_owner` çalıştır
5. `/function custom:menu` ile başla

## 📋 Gereksinimler
- Minecraft Java Edition 1.21.6 – 26.1.2
